IPv4 предоставляет 32-битные адреса источника и назначения для маршрутизируемых пакетов. Адрес имеет смысл вместе со своим префиксом, интерфейсом, областью действия, политикой маршрутизации и сроком жизни, а не как постоянный идентификатор всего устройства.

## Точечно-десятичная запись

IPv4 отображается как четыре восьмибитных октета, разделённых точками:

```text
192.0.2.165
```

Каждый октет имеет диапазон от 0 до 255, поэтому полный адрес содержит четыре байта. Длина префикса определяет, сколько начальных битов относятся к сетевому префиксу, как в `192.0.2.165/24`.

:::single-choice{#ipv4-address-size} Каков размер адреса IPv4?

::option[32 бита в четырёх октетах.]{#ipv4-thirty-two-bits .correct explanation="Четыре группы по восемь бит образуют точечно-десятичное представление."}
::option[24 бита в каждой сети.]{#ipv4-always-twenty-four explanation="/24 — одна длина префикса, а не размер любого адреса IPv4."}
::option[128 байт, разделённых двоеточиями.]{#ipv4-128-bytes explanation="IPv6 имеет размер 128 бит и использует разделённую двоеточиями шестнадцатеричную запись."}
:::

## Область и назначение адреса

Не каждый адрес IPv4 маршрутизируется глобально. К примерам относятся loopback `127.0.0.0/8`, link-local `169.254.0.0/16`, частные диапазоны вроде `10.0.0.0/8` и диапазоны документации вроде `192.0.2.0/24`. У групповых и ограниченных широковещательных адресов другая семантика.

Частные адреса могут повторно использоваться в отдельных сетях. NAT способен преобразовывать их для внешнего взаимодействия, но не нужен для связи внутри частного маршрутизируемого домена.

:::single-choice{#ipv4-private-reuse} Почему `10.0.0.1` может встречаться во многих организациях?

::option[Каждый экземпляр обозначает один и тот же физический маршрутизатор.]{#ipv4-same-router explanation="Адрес имеет смысл внутри каждой сети и не является глобально уникальным."}
::option[Маршрутизаторы IPv4 игнорируют первый октет.]{#ipv4-ignore-octet explanation="Все биты адреса участвуют в сопоставлении маршрута."}
::option[Он находится в диапазоне адресов для повторного использования в частных сетях.]{#ipv4-private-range .correct explanation="Отдельные частные сети могут использовать одинаковые адреса, не объявляя их глобально."}
:::

## Проверка адресов IPv4 в Linux

Отобразите назначения IPv4:

```bash
$ ip -4 address show
```

Такая строка сообщает больше одного адреса:

```text
inet 192.0.2.165/24 brd 192.0.2.255 scope global dynamic eth0
```

Она показывает префикс, широковещательный адрес, область действия, признак динамического происхождения и интерфейс. Дополнительные строки могут сообщать действительный и предпочтительный сроки. Один интерфейс способен иметь несколько адресов IPv4.

:::single-choice{#ipv4-ip-output-prefix} Что означает `/24` в `192.0.2.165/24`?

::option[Срок адреса истекает через 24 секунды.]{#ipv4-prefix-seconds explanation="Срок жизни сообщается отдельно."}
::option[Первые 24 бита адреса образуют сетевой префикс.]{#ipv4-prefix-bits .correct explanation="Оставшиеся восемь бит обозначают позиции внутри этого префикса."}
::option[Интерфейс является TCP-портом 24.]{#ipv4-prefix-port explanation="Запись префикса CIDR не связана с транспортными портами."}
:::

## Определение выбранного источника

Наличие адреса не доказывает, что Linux использует его для конкретного назначения. На выбор источника влияют маршруты, правила политик, метрики и привязка приложения. Запросите текущее решение маршрутизации:

```bash
$ ip route get 198.51.100.20
```

Прочитайте выбранные следующий переход, интерфейс и источник, затем проверьте настоящий путь приложения. Не меняйте адреса удалённого хоста без консольного доступа и плана отката.

:::single-choice{#ipv4-route-get-purpose} Что может показать `ip route get DESTINATION`?

::option[Конфигурацию каждого маршрутизатора на полном пути через интернет.]{#ipv4-all-router-config explanation="Локальный поиск не запрашивает конфигурации последующих устройств."}
::option[Локальное решение маршрутизации, включая интерфейс и предпочтительный источник.]{#ipv4-route-decision .correct explanation="Команда оценивает текущую политику маршрутизации хоста для указанного назначения."}
::option[Пароль пользователя назначения.]{#ipv4-password explanation="Команды маршрутизации не раскрывают учётные данные приложений."}
:::
