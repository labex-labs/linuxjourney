Используйте `compose.yaml` с сервисами `web` и `toolbox` из предыдущего урока. Оба входят в один **проект** Compose — группу ресурсов, которыми управляет эта конфигурация. Выполняйте команды в учебном каталоге.

## Запускаем проект

Если порт 8080 занят, выберите в `compose.yaml` свободный порт хоста. Например, контейнер `published-web` из курса Docker использует порт 8080, пока работает. Его можно оставить запущенным и указать в Compose сопоставление `127.0.0.1:8081:80`, если порт 8081 свободен. Оставьте порт 80 на стороне контейнера, а в следующих запросах из браузера используйте выбранный порт хоста.

Чтобы запустить сервисы в фоновом режиме, выполните `docker compose up -d`. Compose создаёт необходимые ресурсы проекта и создаёт или обновляет контейнеры по настройкам сервисов.

```bash
$ docker compose up -d
```

## Читаем список сервисов

Проверьте проект командой `docker compose ps`. В колонке сервисов указаны имена из файла YAML. Docker также присваивает имя каждому контейнеру. В это имя может входить название проекта.

```bash
$ docker compose ps
```

Найдите `web` и `toolbox` и проверьте их состояние. Запущенный контейнер означает, что программа работает в момент проверки. Чтобы отдельно проверить ответ веб-сервера, отправьте запрос из браузера.

::option[Посчитать сервисы в выводе config.]{#compose-services-compose-list-b explanation="Число сервисов ничего не говорит о том, какую страницу вернёт сервер."}
::option[Отправить запрос по опубликованному веб-адресу.]{#compose-services-compose-list-a .correct explanation="Запрос позволяет проверить, какую страницу сервер действительно отдаёт."}
::option[Посмотреть имя другого контейнера.]{#compose-services-compose-list-c explanation="Имя обозначает конкретный контейнер и не проверяет его сервис."}

## Проверяем остановленный сервис

Контейнер с инструментами используется временно. Если время ожидания истекло или вы остановили контейнер, добавьте `-a`, чтобы Compose показал и остановленные контейнеры. Команда в примере ниже останавливает вспомогательный контейнер этого учебного проекта, оставляя веб-сервис запущенным. Когда захотите продолжить курс, запустите контейнер с инструментами снова.

```bash
$ docker compose stop toolbox
$ docker compose ps -a
$ docker compose start toolbox
```
