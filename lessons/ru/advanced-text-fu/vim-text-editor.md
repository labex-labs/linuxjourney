Vim — настраиваемый текстовый редактор, название которого означает **Vi Improved** («улучшенный Vi»). Он сохраняет модальную модель редактирования исходного `vi` и добавляет многоуровневую отмену, поддержку синтаксиса, сценарии и развитую справочную систему.

## Связь Vim и vi

`vi` — это и исторический редактор, и распространённый интерфейс команд. В одной системе Linux команда `vi` может запускать Vim в режиме повышенной совместимости, а в другой — иную реализацию vi. Не считайте, что любая команда `vi` предоставляет все возможности Vim.

Проверьте, что разрешает текущая оболочка:

```bash
$ command -v vim
/usr/bin/vim
$ command -v vi
/usr/bin/vi
```

Сам по себе найденный путь не доказывает, что `vi` и `vim` — одна и та же реализация. Больше сведений дадут `type -a vi vim` и вывод версии редактора.

## Запуск Vim и открытие файлов

Запустите Vim с безымянным буфером:

```bash
$ vim
```

Чтобы редактировать файл, передайте путь:

```bash
$ vim filename.txt
```

Если `filename.txt` существует и доступен для чтения, Vim загрузит его содержимое в буфер. Если пути ещё нет, Vim откроет новый буфер, связанный с этим именем; файл появится только после успешной записи буфера.

Vim не обходит разрешения файловой системы. Возможность открыть файл не гарантирует, что вашей учётной записи разрешено сохранить изменения по этому пути.

## Встроенные учебные ресурсы

Если в установку Vim входит `vimtutor`, запустите его из оболочки для интерактивного обучения:

```bash
$ vimtutor
```

Внутри Vim нажмите `Esc`, чтобы перейти в нормальный режим, введите `:help` и нажмите Enter — откроется справочная система. После команды можно указать конкретную тему:

```vim
:help user-manual
:help :write
```

Теги справки точны, поэтому знаки пунктуации могут иметь значение. Нажмите `Ctrl+]` на ссылке, чтобы перейти по ней, и `Ctrl+T`, чтобы вернуться.

## Практика на одноразовом файле

Начните с файла в принадлежащем вам каталоге:

```bash
$ printf 'alpha\nbeta\n' > vim-practice.txt
$ vim vim-practice.txt
```

Следующие уроки познакомят с поиском, навигацией, вставкой, редактированием и сохранением. Пока вы не освоили безопасный выход, помните: `Esc` возвращает в нормальный режим, а `:q!` с последующим Enter закрывает текущее окно и отбрасывает несохранённые изменения. Используйте эту команду, только если действительно хотите отказаться от правок.
