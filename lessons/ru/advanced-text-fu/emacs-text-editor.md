GNU Emacs — расширяемый текстовый редактор, поведение которого настраивается на Emacs Lisp. Он поддерживает редактирование обычного текста, режимы программирования, управление файлами и буферами и множество дополнительных пакетов. Освоить базовые команды редактирования можно, не принимая все расширения сразу.

## Проверка и запуск Emacs

Не предполагайте, что Emacs установлен. Проверьте, как оболочка разрешает его имя:

```bash
$ command -v emacs
/usr/bin/emacs
```

Запустите Emacs с обычным выбором способа отображения:

```bash
$ emacs
```

В графическом сеансе может появиться отдельный фрейм. Параметр `-nw`, сокращение от no window system, оставляет Emacs в текущем терминале:

```bash
$ emacs -nw
```

::option[`emacs -w`]{#emacs-window-option explanation="Это не показанная здесь форма параметра, отключающего оконную систему."}
::option[`emacs -nw`]{#emacs-no-window .correct explanation="Параметр `-nw` запрещает Emacs использовать графическую оконную систему и запускает его в терминале."}
::option[`command -v emacs`]{#emacs-check-only explanation="Эта команда лишь проверяет разрешение имени и не запускает редактор."}
:::

## Открытие файла

Чтобы открыть файл при запуске Emacs, передайте путь:

```bash
$ emacs notes.txt
```

Если файл существует, Emacs читает его в буфер. Если его нет, создаётся новый буфер, связанный с этим путём; сам файл появится лишь после успешного сохранения. Возможность записи по-прежнему определяется разрешениями файловой системы.

:::single-choice{#emacs-open-file-buffer} Что обычно делает `emacs notes.txt`, если `notes.txt` ещё не существует?

::option[Открывает новый буфер, связанный с этим путём.]{#emacs-new-file-buffer .correct explanation="В буфере можно набрать содержимое для `notes.txt`, а реальный файл будет создан только при сохранении."}
::option[Создаёт файл на диске до запуска редактора.]{#emacs-immediate-file explanation="Emacs может связать новый буфер с путём, не создавая файл на диске до успешного сохранения."}
::option[Отказывается запускаться, потому что открываемый файл обязан существовать.]{#emacs-refuse-new-file explanation="Emacs позволяет создавать новые файлы через буферы, связанные с отсутствующими путями."}
:::

## Буферы, окна и фреймы

Emacs использует связанные, но разные объекты:

- **Буфер** хранит текст или другое состояние редактора. Содержимое открытого файла находится в буфере.
- **Окно** — область внутри фрейма Emacs, показывающая буфер.
- **Фрейм** — отображение Emacs верхнего уровня: например, графический или терминальный фрейм.

Несколько буферов могут существовать невидимыми, а два окна способны показывать один буфер. Закрытие окна не обязательно уничтожает буфер или удаляет файл.

:::single-choice{#emacs-buffer-definition} Что такое буфер Emacs?

::option[Графический фрейм приложения верхнего уровня.]{#emacs-buffer-frame explanation="Фрейм — объект отображения верхнего уровня, а буфер хранит содержимое или состояние редактора."}
::option[Объект, хранящий редактируемый текст или другое состояние редактора.]{#emacs-buffer-content .correct explanation="Содержимое открытых файлов и многие нефайловые представления находятся в буферах Emacs."}
::option[Файл истории оболочки с предыдущими командами.]{#emacs-buffer-history explanation="История оболочки не относится к хранилищу буферов Emacs."}
:::

## Обозначения клавиш Emacs

Документация Emacs использует краткие обозначения:

- `C-x` означает удерживать Control и нажать `x`.
- `M-x` означает удерживать Meta и нажать `x`; в современных терминалах и графических средах роль Meta часто выполняет Alt.
- `C-x C-f` — последовательность: сначала Control+x, затем Control+f.

Конкретный терминал может перехватывать или переназначать отдельные клавиши. Нередко Meta-сочетание можно заменить последовательным нажатием `Esc` и нужной клавиши.

:::single-choice{#emacs-key-sequence-notation} Как ввести последовательность Emacs `C-x C-f`?

::option[Удерживая Control, нажать `x`, затем, снова удерживая Control, нажать `f`.]{#emacs-control-x-f .correct explanation="Каждый префикс `C-` относится к следующей клавише, а два сочетания вводятся последовательно."}
::option[Ввести в буфер буквальные символы `C-x C-f`.]{#emacs-literal-key-text explanation="Обозначение описывает события клавиш Control, а не текст для вставки."}
::option[Одновременно удерживать Control, `x` и `f` как единое сочетание.]{#emacs-simultaneous-x-f explanation="Запись содержит два последовательных сочетания, а не одно из трёх клавиш."}
:::

## Встроенный учебник

В Emacs нажмите `C-h t`, чтобы открыть интерактивный учебник. Он безопасно знакомит с перемещением, вставкой, сохранением и выходом в учебном буфере. `C-h` — префикс справки, а `C-h C-h` показывает помощь по использованию самой справки.

Если Emacs показывает меню или приветственный буфер, структурированный учебник будет лучшим началом, чем эксперименты с важным файлом.

:::single-choice{#emacs-open-tutorial} Какая последовательность Emacs открывает встроенный учебник?

::option[`C-x C-s`]{#emacs-save-buffer explanation="Эта последовательность сохраняет текущий буфер и не открывает учебник."}
::option[`C-x C-c`]{#emacs-exit-sequence explanation="Эта последовательность начинает выход из Emacs, а не запускает урок."}
::option[`C-h t`]{#emacs-help-tutorial .correct explanation="Префикс справки `C-h` с последующей `t` запускает учебник Emacs."}
:::
