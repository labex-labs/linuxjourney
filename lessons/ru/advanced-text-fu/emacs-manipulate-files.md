Emacs открывает файлы в буферах. Редактирование сначала изменяет буфер, а сохранение записывает его текущее содержимое по связанному пути. Читайте сообщения минибуфера: разрешения, конфликтующие изменения на диске и другие ошибки могут помешать записи.

## Открытие файла

Нажмите `C-x C-f`, что запускает `find-file`, затем введите путь в минибуфере и нажмите Enter:

```text
C-x C-f
```

Emacs открывает существующий доступный файл в буфере либо готовит новый файловый буфер для отсутствующего пути. Во втором случае файла на диске не будет до успешного сохранения.

При вводе пути доступно дополнение клавишей Tab. Открытие каталога обычно запускает редактор каталогов Dired, а не воспринимает каталог как текстовый файл.

:::single-choice{#emacs-find-file-key}
Какая последовательность Emacs запрашивает путь и открывает его?

::option[`C-x C-s`]{#emacs-file-save explanation="Она сохраняет текущий файловый буфер и не запрашивает другой путь для открытия."}
::option[`C-x C-c`]{#emacs-file-exit explanation="Она начинает выход из Emacs, а не открытие файла."}
::option[`C-x C-f`]{#emacs-find-file .correct explanation="Команда `find-file` запрашивает в минибуфере путь, который нужно открыть."}
:::

:::single-choice{#emacs-find-missing-file}
Когда обычно создаётся файл на диске, если `C-x C-f` открывает несуществующий путь?

::option[Только после успешного сохранения нового буфера.]{#emacs-file-created-on-save .correct explanation="Буфер может содержать правки до появления файла, а создаёт его операция сохранения."}
::option[Сразу после ввода пути.]{#emacs-file-created-immediately explanation="Сначала Emacs создаёт связанный с путём буфер, откладывая создание файла на диске."}
::option[Только после закрытия самого Emacs.]{#emacs-file-created-on-exit explanation="При выходе может появиться запрос сохранения, но создание файла связано с успешным сохранением, а не обязательно с закрытием Emacs."}
:::

## Сохранение текущего буфера

Нажмите `C-x C-s`, что запускает `save-buffer`, чтобы сохранить текущий файловый буфер:

```text
C-x C-s
```

Если у буфера нет связанного имени файла, Emacs запросит его. Успешная запись снимает индикатор изменений; при ошибке несохранённые данные остаются в буфере, а Emacs сообщает о проблеме.

:::single-choice{#emacs-save-current-buffer}
Какая последовательность сохраняет текущий файловый буфер?

::option[`C-x C-s`]{#emacs-save-buffer-key .correct explanation="`C-x C-s` запускает `save-buffer` для текущего буфера."}
::option[`C-x C-w`]{#emacs-write-file-key explanation="Она запрашивает другое имя файла и меняет файл, который посещает буфер."}
::option[`C-x s`]{#emacs-save-some-key explanation="Она проверяет несколько файловых буферов и запрашивает их сохранение, а не работает только с текущим."}
:::

## Запись под другим именем

Нажмите `C-x C-w`, что запускает `write-file`: Emacs запросит путь, запишет туда буфер и свяжет его с новым файлом:

```text
C-x C-w
```

Это поведение Emacs «Сохранить как». Оно отличается от простой записи отдельной копии с продолжением работы по исходному пути.

:::single-choice{#emacs-write-file-as}
Какая последовательность выполняет обычную операцию «Сохранить как» для текущего буфера?

::option[`C-x C-f`]{#emacs-find-file-other explanation="Она открывает файл, возможно переключая буфер, но не сохраняет текущий буфер под новым именем."}
::option[`C-x k`]{#emacs-write-as-kill-buffer explanation="Она предлагает уничтожить буфер и может спросить о несохранённых правках, но не сохраняет под новым именем."}
::option[`C-x C-w`]{#emacs-write-file-answer .correct explanation="`write-file` записывает по выбранному пути и делает этот файл посещаемым текущим буфером."}
:::

## Проверка нескольких изменённых буферов

Нажмите `C-x s`, что запускает `save-some-buffers`, чтобы проверить изменённые файловые буферы:

```text
C-x s
```

Обычно Emacs спрашивает, сохранять ли каждый подходящий изменённый буфер. Читайте имя и отвечайте осознанно: это не безусловная команда «сохранить всё».

:::single-choice{#emacs-save-some-buffers}
Что обычно делает `C-x s`?

::option[Запрашивает сохранение изменённых файловых буферов.]{#emacs-prompt-save-some .correct explanation="`save-some-buffers` проверяет подходящие изменённые буферы и спрашивает, какие из них записать."}
::option[Молча сохраняет каждый буфер без показа имён.]{#emacs-silent-save-all explanation="Обычная интерактивная команда задаёт вопросы, а не безусловно записывает всё."}
::option[Закрывает все буферы после сохранения текущего.]{#emacs-close-all-buffers explanation="Команда касается сохранения нескольких буферов и обычно не закрывает их."}
:::

## Перечитывание с диска

Если файл изменился на диске и вы намеренно хотите отбросить текущее содержимое буфера, выполните `M-x revert-buffer` и внимательно проверьте запрос подтверждения. Перечитывание может уничтожить несохранённые правки, поэтому сначала решите, какой источник должен победить.

Перед решением можно сохранить отдельную копию либо воспользоваться системой контроля версий и инструментами сравнения. Не считайте перезагрузку безвредной для изменённого буфера.

## Итоги

Теперь вы умеете управлять файловыми буферами, не путая открытие с записью.

1. Открывать путь через `C-x C-f`.
2. Создавать отсутствующий файл только при сохранении его буфера.
3. Сохранять текущий буфер через `C-x C-s`.
4. Сохранять под новым посещаемым именем через `C-x C-w`.
5. Проверять несколько изменённых буферов через `C-x s`.
