Модуль Python `http.server` может раздавать статические файлы для кратковременного теста или доверенной передачи. Это не производственный веб-сервер: он не предоставляет аутентификацию, авторизацию, TLS, ограничение частоты запросов или усиленную обработку враждебного трафика.

## Подготовка общего каталога

Создайте отдельный каталог только с теми файлами, которые предполагается открыть. Перед запуском проверьте скрытые файлы, символические ссылки, права и конфиденциальные метаданные. Не раздавайте домашний каталог, корень репозитория, каталог учётных данных или системный путь.

Сделайте общий корень явным с помощью `--directory`:

```bash
$ python3 -m http.server 8000 --directory /srv/temporary-share
```

Если индексного файла нет, модуль обычно создаёт список каталога. Любой, кто может обратиться к прослушиваемому адресу, потенциально способен перечислить и загрузить раздаваемое содержимое.

:::single-choice{#http-server-directory-option} Зачем использовать `--directory /srv/temporary-share`?

::option[Параметр автоматически шифрует каждый ответ HTTP.]{#http-server-directory-tls explanation="Параметр каталога не добавляет TLS."}
::option[Параметр создаёт учётную запись для каждого получателя.]{#http-server-directory-accounts explanation="Базовый модуль не предоставляет аутентификацию пользователей."}
::option[Параметр явно задаёт требуемый корень документов.]{#http-server-explicit-root .correct explanation="Явный проверенный корень снижает риск раскрыть файлы из случайного рабочего каталога."}
:::

## Управление адресом прослушивания

Если подключаться должен только тот же хост, привяжите сервер к обратной петле:

```bash
$ python3 -m http.server 8000 --bind 127.0.0.1 --directory /srv/temporary-share
```

Для общего доступа в доверенной сети осознанно привяжитесь к подходящему адресу интерфейса и проверьте политику межсетевого экрана. Запуск без ограничивающей привязки обычно прослушивает все доступные интерфейсы, из-за чего каталог может оказаться открыт шире требуемой сети.

:::single-choice{#http-server-loopback-bind} Кто обычно может обратиться к серверу, привязанному к `127.0.0.1`?

::option[Клиенты на том же хосте.]{#http-server-local-clients .correct explanation="Привязка к обратной петле подходит для локального тестирования или работы за намеренно настроенным туннелем."}
::option[Любой хост в общедоступном интернете.]{#http-server-public explanation="Обратная петля локальна для того же сетевого пространства имён и не является общедоступным интерфейсом."}
::option[Только устройства, подключённые по Bluetooth.]{#http-server-bluetooth explanation="Этот адрес не связан с транспортом Bluetooth."}
:::

## Проверка доступа

На раздающем хосте запросите известный файл и проверьте ответ:

```bash
$ curl -f http://127.0.0.1:8000/example.txt
```

Для разрешённого удалённого теста используйте выбранный адрес интерфейса вместо обратной петли. Убедитесь и в доступности нужного файла, и в недоступности файла за пределами корня документов. Сам по себе успех в браузере не подтверждает правильную область раскрытия или конфиденциальность.

:::single-choice{#http-server-default-port-command} Какой порт явно выбран в команде `python3 -m http.server 8000`?

::option[22]{#http-server-port-22 explanation="Порт 22 обычно связан с SSH и здесь не выбран."}
::option[8000]{#http-server-port-8000 .correct explanation="Позиционный операнд порта указывает модулю, где прослушивать соединения."}
::option[443]{#http-server-port-443 explanation="Команда не настраивает HTTPS на порту 443."}
:::

## Остановка и очистка

Запускайте временную службу в контролируемом терминале и после завершения передачи остановите её сочетанием `Ctrl-C`. Убедитесь, что прослушивание исчезло:

```bash
$ ss -ltn 'sport = :8000'
```

Удалите временные копии согласно правилам обработки данных и отмените временное правило межсетевого экрана. Для постоянной, аутентифицированной или доступной из интернета раздачи используйте поддерживаемый сервер с настроенными управлением доступом и TLS.

:::single-choice{#http-server-completion-check} Что следует сделать после завершения временной передачи?

::option[Остановить сервер и убедиться, что порт больше не прослушивается.]{#http-server-stop-verify .correct explanation="Проверка подтверждает, что временная сетевая служба действительно завершилась."}
::option[Оставить сервер работать на случай, если он понадобится позднее.]{#http-server-leave-running explanation="Ненужное раскрытие следует устранить после выполнения разрешённой задачи."}
::option[Скопировать дополнительные личные файлы в корень документов.]{#http-server-add-private explanation="В раздаваемом каталоге должно находиться только намеренно открытое содержимое."}
:::

## Итоги

Теперь вы можете запускать временный HTTP-сервер Python с ограниченной областью раскрытия.

1. Раздавайте только отдельный проверенный каталог.
2. Привязывайтесь к наиболее узкому подходящему адресу.
3. Проверяйте требуемый доступ и нежелательные границы.
4. После работы останавливайте прослушивание и удаляйте временный доступ.
