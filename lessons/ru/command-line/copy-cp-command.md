Команда `cp` копирует файлы и каталоги, оставляя источник на месте. Базовый синтаксис:

```bash
cp [OPTIONS] SOURCE DESTINATION
```

Можно скопировать один файл по другому пути, несколько файлов в каталог или рекурсивно — целое дерево каталогов.

## Копирование одного файла

Сначала указывается источник, затем назначение:

```bash
$ cp mycoolfile /home/pete/Documents/cooldocs
```

Если `/home/pete/Documents/cooldocs` — существующий каталог, копия появится внутри него под именем `mycoolfile`. Можно указать и новое имя назначения:

```bash
$ cp mycoolfile /home/pete/Documents/mycoolfile_backup
```

Во втором примере скопированные данные получают имя `mycoolfile_backup`.

::option[`mv draft.txt final.txt`]{#move-draft explanation="`mv` переименовывает или перемещает исходный путь и не оставляет требуемую копию источника."}

:::

## Копирование нескольких файлов в каталог

Сначала перечислите источники, а каталог назначения поставьте последним:

```bash
$ cp report.txt notes.txt summary.txt /home/pete/Documents/
```

При нескольких источниках последний аргумент обязан быть каталогом.

:::single-choice{#copy-multiple-files}
Какая команда копирует `a.txt` и `b.txt` в существующий каталог `archive/`?

::option[`cp archive/ a.txt b.txt`]{#destination-first explanation="В этой форме каталог назначения должен стоять в конце; иное расположение меняет интерпретацию аргументов."}
::option[`cp a.txt b.txt archive/`]{#destination-last .correct explanation="При нескольких источниках `cp` воспринимает последний существующий каталог как назначение для всех предыдущих файлов."}
::option[`cp a.txt archive/ b.txt`]{#destination-middle explanation="Все источники должны предшествовать назначению, а существующий каталог — быть последним аргументом."}
:::

## Выбор файлов подстановочными шаблонами

Оболочка раскрывает шаблоны в несколько исходных путей:

- `*`: любая последовательность символов.
- `?`: любой один символ.
- `[]`: один из символов в скобках.

Например, скопируем имена на `.jpg` из текущего каталога в `Pictures`:

```bash
$ cp *.jpg /home/pete/Pictures
```

Перед массовым копированием проверьте совпадения, особенно если в назначении важные данные:

```bash
$ ls *.jpg
beach.jpg  lunch.jpg  profile.jpg
$ cp *.jpg /home/pete/Pictures
```

:::single-choice{#preview-copy-pattern}
Какая команда перед копированием `*.jpg` показывает совпавшие нескрытые имена?

::option[`cp *.jpg`]{#copy-no-destination explanation="Это попытка копирования без ясного назначения при нескольких совпадениях, а не предварительный просмотр."}
::option[`ls *.jpg`]{#list-jpg-matches .correct explanation="Оболочка раскрывает для `ls` тот же шаблон, позволяя проверить имена до копирования."}
::option[`file '*.jpg'`]{#quoted-jpg-pattern explanation="Кавычки запрещают раскрытие, поэтому `file` получает буквальные символы `*.jpg`."}
:::

## Копирование деревьев каталогов

Для каталога со всем содержимым нужна рекурсия через `-r` или `-R`:

```bash
$ cp -r Pumpkin/ /home/pete/Documents
```

Так каталог `Pumpkin` со всеми потомками копируется в `Documents`.

Прописная `-R` тоже включает рекурсию:

```bash
$ cp -R website /home/pete/backups/
```

Архивный режим `-a` удобен для резервных копий: он копирует рекурсивно, сохраняя ссылки и многие атрибуты.

```bash
$ cp -a project/ project-backup/
```

:::single-choice{#archive-directory-tree}

::option[`cp -p project/ project-backup/`]{#preserve-directory-only explanation="`-p` сохраняет отдельные атрибуты, но сам по себе не включает рекурсивное копирование каталога."}
::option[`cp -u project/ project-backup/`]{#update-directory-only explanation="`-u` управляет копированием по состоянию назначения, но сам не включает рекурсию."}
::option[`cp -a project/ project-backup/`]{#archive-project .correct explanation="Архивный режим включает рекурсию и сохраняет ссылки и широкий набор атрибутов."}
:::

## Управление перезаписью

По умолчанию `cp` может заменить существующий файл назначения. Параметр `-i` запрашивает подтверждение:

```bash
$ cp -i mycoolfile /home/pete/Pictures
cp: overwrite '/home/pete/Pictures/mycoolfile'? n
```

Параметр `-n` запрещает перезаписывать существующее назначение:

```bash
$ cp -n mycoolfile /home/pete/Pictures
```

GNU `cp -f` при невозможности открыть назначение для записи пытается удалить его и повторить копирование. Это не заменяет проверку целей. Псевдонимы оболочки тоже могут добавлять параметры вроде `-i`, поэтому неожиданный запрос следует исследовать.

:::single-choice{#skip-existing-destination}
Какая команда копирует `report.txt` в `backup/`, но пропускает существующий одноимённый файл?

::option[`cp -n report.txt backup/`]{#no-clobber-report .correct explanation="Параметр `-n` запрещает `cp` перезаписывать существующее назначение."}
::option[`cp -i report.txt backup/`]{#interactive-report explanation="`-i` задаёт вопрос, поэтому результат зависит от ответа и не всегда пропускает назначение."}
::option[`cp -f report.txt backup/`]{#force-report explanation="`-f` помогает заменить назначение, а не обеспечивает запрет перезаписи."}
:::

## Сохранение атрибутов и обновление

`-p` сохраняет режим, при наличии разрешений владельца и временные метки источника:

```bash
$ cp -p mycoolfile /home/pete/backups/
```

`-u` копирует источник только при отсутствии назначения или если источник новее:

```bash
$ cp -u *.txt /home/pete/Documents/
```

Другие параметры:

- `-f`: при необходимости удалить назначение перед принудительной записью.
- `-v`: показывать каждый копируемый файл.

## Итоги

Теперь вы умеете копировать файлы и деревья каталогов, управляя назначениями.

1. Ставить источники перед назначением.
2. Проверять совпадения шаблона до массовой операции.
3. Копировать деревья рекурсивно или в архивном режиме.
4. Подтверждать, пропускать или намеренно заменять назначения.
5. Сохранять атрибуты или копировать только более новые источники.
