Интерактивные оболочки могут хранить введённые команды. Здесь рассматривается Bash, где встроенная команда `history` показывает и управляет этой записью. Другие оболочки могут использовать иные клавиши, файлы и настройки.

## Просмотр истории Bash

Запустите `history` для вывода текущего списка:

```bash
$ history
  101  pwd
  102  ls -la
  103  cat notes.txt
```

Каждая строка содержит номер истории и команду.

## Повторное использование команд

Bash предоставляет несколько способов вызвать или сразу выполнить команды:

- **Стрелка вверх**: вернуть предыдущую команду для проверки или редактирования.
- **`!!`**: раскрыть и выполнить последнюю команду.
- **По номеру**: `!102` выполняет запись 102.
- **По префиксу**: `!cat` выполняет последнюю команду, начинавшуюся с `cat`.

Расширения с `!` могут выполнить команду сразу после Enter. При сомнении сначала проверьте совпадение, особенно перед добавлением повышенных прав или работой с важными файлами.

:::single-choice{#repeat-most-recent-command} Какое расширение истории Bash повторяет последнюю выполненную команду?

::option[`!102`]{#event-number explanation="Оно выбирает запись с номером 102, которая не обязательно является последней."}
::option[`!cat`]{#event-prefix explanation="Оно выбирает последнюю команду с префиксом `cat`, а не последнюю команду любого вида."}
::option[`!!`]{#previous-event .correct explanation="В Bash `!!` раскрывается в предыдущую команду и выполняет её после отправки строки."}
:::

## Интерактивный поиск истории

Нажмите `Ctrl+R`, затем вводите часть нужной команды. Повторное `Ctrl+R` переходит к более старому совпадению.

Enter выполнит показанную команду. Чтобы сначала проверить или изменить её, стрелкой перенесите команду в строку редактирования.

## Управление списком истории

Встроенная команда умеет менять и сохранять список:

- `history -c`: очистить текущую историю в памяти.
- `history -w`: записать текущий список в настроенный файл, обычно `~/.bash_history`.
- `history -d <offset>`: удалить запись в указанной позиции.

Примеры:

```bash
$ history -d 101
$ history -w
```

Очистка списка в памяти не гарантирует исчезновения старых команд из всех файлов, резервных копий и других активных оболочек. Поведение зависит от настроек Bash и времени чтения и записи файлов сеансами.

::option[`history -d 101`]{#delete-one-entry explanation="`-d` удаляет выбранную запись и не сохраняет полный список."}

## Очистка экрана и дополнение имён

Команда `clear` обновляет видимую область терминала:

```bash
$ clear
```

Она не стирает историю Bash. В зависимости от терминала прежний вывод может оставаться и в буфере прокрутки.

Дополнение по Tab помогает не вводить имена заново. Начните команду, имя файла или каталога и нажмите Tab. Bash может дополнить однозначное совпадение или показать варианты.

Командные строки попадают в историю, поэтому не помещайте пароли, токены и другие секреты прямо в команды, если есть более безопасный способ ввода.

::option[`clear`]{#clear-visible-area .correct explanation="`clear` обновляет видимую область, оставляя список истории Bash в памяти."}
::option[`history -c`]{#clear-memory explanation="Она удаляет записи текущего списка в памяти, а не только очищает экран."}
