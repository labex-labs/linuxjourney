Запоминать все параметры не нужно. Bash и многие программы объясняют синтаксис прямо в терминале, но источник справки зависит от вида команды.

## Справка по встроенным командам Bash

Bash предоставляет встроенную `help` для команд самой оболочки, например `cd`, `history` и `type`.

Передайте имя встроенной команды:

```bash
$ help echo
```

Вывод описывает синтаксис и поведение. `help` без аргумента перечисляет встроенные команды, для которых доступна справка.

:::single-choice{#help-for-bash-cd}
Какая команда показывает справочную запись Bash для встроенной `cd`?

::option[`cd --help`]{#cd-help-option explanation="Некоторые встроенные команды распознают параметры, но специальный интерфейс документации Bash — `help` с именем."}
::option[`help cd`]{#help-cd .correct explanation="Встроенная `help` ищет документацию указанной встроенной команды, здесь `cd`."}
::option[`type cd`]{#type-cd explanation="`type` показывает, как Bash разрешает имя `cd`, но не полную справочную запись."}
:::

## Краткая справка программы

Многие внешние программы по соглашению принимают `--help` и печатают краткое использование:

```bash
$ ls --help
```

Соглашение распространено, но не универсально. Читайте вывод и код завершения, не предполагая поддержку одним и тем же образом.

:::single-choice{#quick-ls-usage}
Какая команда обычно показывает краткую справку внешней программы `ls`?

::option[`help ls`]{#bash-help-ls explanation="Bash `help` документирует встроенные команды и обычно не предоставляет страницу внешней `ls`."}
::option[`ls --help`]{#ls-help .correct explanation="GNU `ls` следует соглашению `--help` и выводит использование и параметры."}
::option[`type --help ls`]{#type-help-ls explanation="Это обращается к обработке параметров самой встроенной `type`, а не просит `ls` объяснить использование."}
:::

## Определение разрешения имени Bash

`type` показывает, является ли имя встроенной командой, псевдонимом, функцией, ключевым словом или исполняемым файлом:

```bash
$ type cd
cd is a shell builtin
$ type ls
ls is /usr/bin/ls
```

Точный результат зависит от псевдонимов, функций, установленных программ и `PATH`. `type -a NAME` показывает все известные разрешения, а не только первое.

:::single-choice{#identify-command-resolution}
Вы не знаете, является ли `deploy` псевдонимом, функцией, встроенной командой или файлом. Чем проверить?

::option[`type deploy`]{#type-deploy .correct explanation="Встроенная `type` сообщает, как текущая среда Bash интерпретирует имя."}
::option[`help deploy`]{#help-deploy explanation="`help` ищет документацию встроенных команд и обычно не определяет псевдонимы, функции и внешние файлы."}
::option[`deploy --help`]{#deploy-help explanation="Это пытается запустить команду и зависит от её поддержки параметра, не объясняя сначала разрешение имени."}
:::

## Выбор подробности

- `help COMMAND` — для встроенной команды Bash.
- `COMMAND --help` — краткая справка многих внешних программ.
- `man COMMAND` — установленная подробная man-страница.
- `whatis COMMAND` — однострочное описание.

Следующие уроки подробнее рассматривают man-страницы и краткие описания.

:::single-choice{#choose-detailed-manual}
Вам нужна подробная документация внешней `ls`, а не краткая справка. Что попробовать?

::option[`man ls`]{#man-ls .correct explanation="`man ls` открывает установленную страницу с более полным описанием синтаксиса, параметров и поведения."}
::option[`whatis ls`]{#whatis-ls explanation="`whatis` показывает краткие описания, а не требуемую подробную документацию."}
::option[`type ls`]{#type-ls explanation="`type` сообщает разрешение имени и не показывает подробное руководство программы."}
:::
