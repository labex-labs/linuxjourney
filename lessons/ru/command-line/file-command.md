В предыдущем уроке `touch` создала файл без расширения. В Linux имя не обязано описывать содержимое: файл `funny.gif` не обязательно является изображением GIF.

Команда `file` исследует файл и сообщает его вероятный тип:

```bash
$ file banana.jpg
banana.jpg: JPEG image data
```

## Почему расширения недостаточно

Инструментам Linux обычно не нужно расширение для определения типа. Сценарий оболочки может называться `backup`, текст — `README`, а изображение может иметь вводящее в заблуждение расширение. `file` исследует свойства вроде метаданных файловой системы и распознаваемых шаблонов содержимого.

```bash
$ file README
README: ASCII text
$ file /bin/ls
/bin/ls: ELF 64-bit LSB executable
```

Результат — классификация, а не гарантия. Необычный, неполный или повреждённый файл может получить общее описание `data` вместо точного типа.

:::single-choice{#identify-misleading-extension} Файл `report.jpg` может не содержать изображение. Какая команда проверит вероятный тип содержимого?

::option[`ls report.jpg`]{#list-report explanation="`ls` подтверждает наличие имени и показывает метаданные, но не классифицирует содержимое."}
::option[`file report.jpg`]{#inspect-report .correct explanation="`file` исследует файл и сообщает вероятный тип, не полагаясь только на суффикс `.jpg`."}
::option[`touch report.jpg`]{#touch-report explanation="`touch` обновляет метки или создаёт отсутствующий файл, но не определяет тип содержимого."}
:::

## Проверка нескольких файлов

Несколько файлов можно проверить сразу:

```bash
$ file notes.txt image.png archive.tar.gz
notes.txt: ASCII text
image.png: PNG image data
archive.tar.gz: gzip compressed data
```

Можно передать и подстановочный шаблон оболочки. Сначала оболочка раскрывает `*` в подходящие имена, затем `file` исследует их:

```bash
$ file *
```

:::single-choice{#inspect-multiple-files} Какая команда просит `file` проверить все нескрытые имена текущего каталога, совпавшие с `*`?

::option[`file *`]{#file-wildcard .correct explanation="Оболочка раскрывает `*` в подходящие нескрытые имена, а `file` исследует каждый получившийся аргумент."}
::option[`file .`]{#file-current-directory explanation="Одна точка обозначает сам текущий каталог, поэтому команда классифицирует каталог, а не каждую запись внутри."}
::option[`file -b`]{#file-brief-no-operand explanation="Параметр `-b` меняет формат вывода, но команда не содержит файлов для проверки."}
:::

## Вывод MIME-информации

Параметр `-i` печатает сведения в стиле MIME: тип медиа и, если возможно, кодировку. Такой вид полезен программам, ожидающим значения вроде `text/html`.

```bash
$ file -i index.html
index.html: text/html; charset=us-ascii
```

:::single-choice{#show-mime-information} Какая команда выводит MIME-информацию для `index.html`?

::option[`file -b index.html`]{#brief-index explanation="`-b` убирает имя из обычного описания, но не запрашивает MIME-формат."}
::option[`file -i index.html`]{#mime-index .correct explanation="Параметр `-i` запрашивает MIME-вывод, например `text/html` вместе со сведениями о кодировке."}
::option[`file -L index.html`]{#follow-index explanation="`-L` управляет обработкой символических ссылок, а не форматом MIME."}
:::

## Полезные параметры file

- `-i`: показать MIME-информацию.
- `-b`: краткий режим без имени файла в выводе.
- `-L`: следовать символическим ссылкам и классифицировать их цели.
- `-z`: попытаться исследовать содержимое сжатых файлов.

Например:

```bash
$ file -b notes.txt
ASCII text
```

:::single-choice{#omit-filename-from-output} Какая команда классифицирует `notes.txt`, но не выводит его имя?

::option[`file -i notes.txt`]{#mime-notes explanation="`-i` запрашивает MIME-информацию, но вывод по-прежнему обычно содержит имя файла."}
::option[`file -z notes.txt`]{#compressed-notes explanation="`-z` просит по возможности заглянуть в сжатые данные, но не включает краткий вывод."}
::option[`file -b notes.txt`]{#brief-notes .correct explanation="Краткий режим `-b` печатает классификацию без префикса с именем файла."}
:::

## Итоги

Теперь вы умеете с помощью `file` исследовать вероятное содержимое файла.

1. Классифицировать файл, не доверяя расширению.
2. Проверять несколько путей одной командой.
3. Запрашивать MIME-информацию.
4. Настраивать обработку ссылок, сжатых данных и подписей вывода.
