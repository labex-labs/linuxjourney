Оболочки могут быть вложенными: графический терминал запускает оболочку, SSH — удалённую, а одна оболочка может запустить другую. Выход обычно возвращает управление тому, кто запустил текущую.

## Выход из текущей оболочки

Команда `exit` просит текущую оболочку завершиться:

```bash
$ exit
```

Если оболочка является главным процессом вкладки терминала, вкладка может закрыться согласно настройкам. В SSH выход из удалённой оболочки возвращает в локальную. При вложенной оболочке `exit` возвращает в родительскую.

::option[`exit`]{#exit-nested .correct explanation="`exit` завершает текущую оболочку, позволяя родительской продолжить работу."}

## Возврат кода завершения

Необязательное число задаёт код, возвращаемый вызывающей стороне:

```bash
$ exit 0
```

По соглашению `0` означает успех, а ненулевое значение — ошибку или иное условие программы. Без числа Bash завершится с кодом последней команды перед `exit`.

::option[`exit 1`]{#exit-one explanation="Ненулевой код обычно означает ошибку или исключительный результат, а не успех."}

## logout в логиновой оболочке

Встроенная Bash `logout` завершает логиновую оболочку:

```bash
$ logout
```

В нелогиновом Bash она сообщает, что оболочка не логиновая; используйте `exit`.

:::single-choice{#leave-login-shell}
Какая встроенная команда Bash специально предназначена для выхода из логиновой оболочки?

## Ctrl+D и закрытие терминала

В пустом интерактивном приглашении `Ctrl+D` обычно передаёт терминальный символ конца файла. Bash часто воспринимает это как запрос выхода. Это не сигнал, а настройки вроде Bash `ignoreeof` могут изменить поведение.

Закрытие графического окна просит терминал завершить процессы и может повлиять на активные задания. По возможности используйте упорядоченный `exit` и проверяйте текущую работу до закрытия сеанса.

## Итоги

Теперь вы умеете выходить из текущей оболочки и сообщать код завершения.

1. Использовать `exit` для возврата вызывающей стороне.
2. Передавать `0` для успеха или определённый ненулевой код иначе.
3. Понимать код голой `exit`.
4. Использовать `logout` только для логиновой оболочки.
5. Распознавать `Ctrl+D` как конец ввода, а не сигнал.
