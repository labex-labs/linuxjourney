Табуляция хранит переход к следующей позиции табуляции, а не фиксированное число видимых пробелов. Её отображаемая ширина зависит от текущего столбца и настройки позиций. Команды `expand` и `unexpand` преобразуют символы табуляции и пробелы друг в друга с учётом этих позиций.

## Преобразование табуляций в пробелы

`expand` читает ввод, заменяет табуляции числом пробелов, необходимым для достижения нужной позиции, и записывает результат в stdout:

```bash
$ expand sample.txt
```

По умолчанию позиции табуляции располагаются через каждые 8 столбцов. Поэтому табуляция в столбце 1 раскрывается иначе, чем в столбце 6; она не всегда заменяется восемью пробелами.

:::single-choice{#expand-default-tab-stops} Как `expand` заменяет символ табуляции с настройками по умолчанию?

::option[Вставляет столько пробелов, сколько нужно до следующей стандартной позиции табуляции.]{#expand-next-stop .correct explanation="`expand` сохраняет выравнивание по позициям табуляции, вычисляя нужное число пробелов от текущего столбца."}
::option[Всегда вставляет ровно восемь пробелов.]{#expand-eight-spaces explanation="Стандартные позиции разделены восемью столбцами, но число пробелов зависит от текущего столбца."}
::option[Удаляет табуляцию, ничего не добавляя.]{#expand-remove-tab explanation="Команда заменяет табуляцию пробелами, чтобы следующий текст сохранил выравнивание по выбранной позиции."}
:::

## Выбор позиций табуляции

Используйте `-t NUMBER`, чтобы разместить позиции табуляции через заданное число столбцов. Для интервала в четыре столбца:

```bash
$ expand -t 4 sample.txt
```

GNU `expand` также принимает разделённый запятыми список явных позиций. Используйте `-i`, если нужно преобразовывать только табуляции перед первым непробельным символом каждой строки.

:::single-choice{#expand-four-column-stops} Какая команда преобразует табуляции с позициями через каждые четыре столбца?

::option[`expand -i 4 sample.txt`]{#expand-initial-four explanation="Параметр `-i` ограничивает преобразование начальными табуляциями и не принимает `4` как интервал позиций."}
::option[`unexpand -t 4 sample.txt`]{#unexpand-tabs-four explanation="`unexpand` преобразует подходящие пробелы в табуляции — в направлении, обратном требуемому."}
::option[`expand -t 4 sample.txt`]{#expand-tabs-four .correct explanation="Параметр `-t` задаёт интервал позиций табуляции, а `4` требует размещать их через четыре столбца."}
:::

## Безопасное сохранение преобразованного вывода

`expand` не редактирует входной файл. Чтобы сохранить преобразованный текст, перенаправьте stdout в другой путь:

```bash
$ expand sample.txt > result.txt
```

Не используйте `expand sample.txt > sample.txt`. Оболочка усекает файл назначения до того, как `expand` успевает его прочитать, поэтому исходные данные могут быть потеряны. Проверив отдельно записанный результат, можно намеренно заменить оригинал подходящей операцией управления файлами.

:::single-choice{#expand-safe-output-file} Какая команда сохраняет раскрытый текст, не усекая `sample.txt` до чтения?

::option[`expand sample.txt > sample.txt`]{#expand-same-file explanation="Оболочка открывает и усекает `sample.txt` для вывода до запуска `expand`, что может стереть входные данные."}
::option[`expand sample.txt > result.txt`]{#expand-separate-result .correct explanation="Пути ввода и вывода различаются, поэтому оболочка может создать `result.txt`, не уничтожая источник."}
::option[`> sample.txt expand result.txt`]{#expand-leading-redirection explanation="Эта запись также усекает `sample.txt` и не задаёт безопасное преобразование исходного файла."}
:::

## Преобразование пробелов в табуляции

`unexpand` заменяет подходящие пробелы табуляциями, сохраняя выравнивание по выбранным позициям. По умолчанию GNU `unexpand` преобразует только начальные пробельные символы перед первым непробельным символом строки:

```bash
$ unexpand result.txt
```

Используйте `-a`, чтобы рассматривать подходящие пробельные символы по всей строке:

```bash
$ unexpand -a result.txt
```

Команда не просто заменяет каждую последовательность из восьми пробелов. Преобразование зависит от столбцов и позиций табуляции, как и у `expand`. Если файл использует другое соглашение, задайте его через `-t 4` или иную спецификацию позиций.

:::single-choice{#unexpand-default-scope} Какие пробелы GNU `unexpand` обычно рассматривает без `-a`?

::option[Каждую группу пробелов в любом месте файла.]{#unexpand-every-group explanation="Для рассмотрения пробелов по всей строке нужен `-a`, причём преобразование всё равно зависит от позиций табуляции."}
::option[Только пробелы после последнего слова.]{#unexpand-trailing-blanks explanation="Стандартная область относится к начальным пробельным символам, а не специально к завершающим."}
::option[Только начальные пробельные символы перед первым непробельным.]{#unexpand-initial-blanks .correct explanation="По умолчанию GNU `unexpand` ограничивается начальными пробельными символами каждой строки."}
:::

:::single-choice{#unexpand-all-blanks} Какой параметр предписывает GNU `unexpand` рассматривать также пробелы после первого непробельного символа?

::option[`-i`]{#unexpand-initial-option explanation="У `expand` параметр `-i` ограничивает работу начальными табуляциями. Для `unexpand` это не параметр всех пробелов."}
::option[`-a`]{#unexpand-all-option .correct explanation="Параметр `-a` разрешает преобразование подходящих пробельных символов по всей входной строке."}
::option[`-t`]{#unexpand-tab-list-option explanation="Параметр `-t` задаёт позиции табуляции. Хотя в GNU он может подразумевать более широкое преобразование, именно `-a` явно требует рассматривать все пробелы."}
:::

Обе команды читают stdin, если файл не указан, поэтому их можно использовать в конвейерах. Помните: преобразование в пробелы и обратно может не восстановить исходный выбор табуляций и пробелов, даже если видимое выравнивание не изменилось.

## Итоги

Теперь вы можете преобразовывать табуляции и пробелы, сохраняя выравнивание по позициям табуляции.

1. Раскрывайте табуляции до следующей настроенной позиции.
2. Задавайте собственные позиции параметром `-t`.
3. Сохраняйте вывод в другой файл перед заменой входного.
4. По умолчанию преобразовывайте начальные пробелы командой `unexpand`.
5. Используйте `-a`, когда нужно рассматривать пробелы по всей строке.
