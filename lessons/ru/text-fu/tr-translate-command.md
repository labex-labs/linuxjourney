Команда `tr`, сокращение от translate, преобразует, удаляет или сжимает символы, прочитанные из stdin. Она не принимает обычные операнды входных файлов, поэтому предоставляйте данные через конвейер или перенаправление ввода.

Основной синтаксис:

```bash
tr [OPTIONS] SET1 [SET2]
```

`tr` работает с наборами символов, а не со словами или общими регулярными выражениями. Если преобразование зависит от полного слова, структуры строки или окружающего контекста, используйте другой инструмент.

## Преобразование символов

При двух наборах символы из `SET1` сопоставляются по позициям символам из `SET2`:

```bash
$ echo "hello world" | tr a-z A-Z
HELLO WORLD
```

Здесь позиции диапазона строчных букв сопоставляются соответствующим прописным. Заключайте выражения наборов в кавычки, чтобы оболочка передавала их без изменений.

Можно также заменять один символ другим:

```bash
$ echo "2026-06-23" | tr '-' '/'
2026/06/23
```

```bash
$ echo "abc123" | tr 'abc' 'ABC'
ABC123
```

Символы, не входящие в `SET1`, проходят без изменений.

::option[`ABCABC`]{#tr-uppercase-digits explanation="Цифры не входят в исходный набор, поэтому `tr` не заменяет их буквами."}
::option[`ABC123`]{#tr-uppercase-abc .correct explanation="Каждая из букв `a`, `b` и `c` сопоставляется символу в той же позиции `ABC`, а цифры не меняются."}
::option[`abc123ABC`]{#tr-append-set explanation="`tr` преобразует совпавшие входные символы и не добавляет набор назначения к потоку."}
:::

## Удаление символов

Используйте `-d` с одним набором, чтобы удалить каждый совпадающий символ:

```bash
$ echo "My address is 123 Main Street" | tr -d '0-9'
My address is  Main Street
```

Каждая цифра удаляется независимо; `tr` не распознаёт число как цельный токен.

Классы символов описывают группы, определяемые текущей локалью:

```bash
$ echo "Hello, world!" | tr -d '[:punct:]'
Hello world
```

Удаление переводов строк объединяет входные строки без вставки разделителя:

```bash
$ printf "one\ntwo\nthree\n" | tr -d '\n'
onetwothree
```

:::single-choice{#tr-delete-digits}
Какая команда удаляет из stdin все цифры, оставляя другие символы без изменений?

::option[`tr -d '[:digit:]'`]{#tr-delete-digit-class .correct explanation="Параметр `-d` удаляет из входного потока все символы класса цифр."}
::option[`tr -s '[:digit:]'`]{#tr-squeeze-digits explanation="Параметр `-s` сжимает повторяющиеся цифры, но оставляет по одному символу из каждой последовательности."}
::option[`tr '[:digit:]'`]{#tr-one-set-no-delete explanation="Для преобразования обычно нужен второй набор. Один набор не запрашивает удаление."}
:::

## Сжатие повторяющихся символов

Используйте `-s SET`, чтобы заменить каждую последовательность указанного символа одним его экземпляром:

```bash
$ echo "Hello      World,   how   are   you?" | tr -s ' '
Hello World, how are you?
```

Набор содержит обычный пробел, поэтому эта команда не сжимает табуляции и переводы строк.

Можно сжимать и повторяющиеся переводы строк:

```bash
$ printf "one\n\n\nTwo\n" | tr -s '\n'
one
Two
```

:::single-choice{#tr-squeeze-spaces}
Какая команда сокращает каждую последовательность обычных пробелов в stdin до одного пробела?

::option[`tr -s ' '`]{#tr-squeeze-space .correct explanation="Параметр `-s` сжимает повторяющиеся элементы указанного набора, который содержит один обычный пробел."}
::option[`tr -d ' '`]{#tr-delete-space explanation="Параметр `-d` удаляет все обычные пробелы, а не сохраняет один из каждой последовательности."}
::option[`tr ' ' ''`]{#tr-empty-destination explanation="Пустой набор преобразования — не ясный и переносимый способ запросить сжатие. Для повторов используйте `-s`."}
:::

## Классы символов и дополнения

Во многих локалях классы символов яснее выражают намерение, чем записанные вручную диапазоны. Распространённые классы:

- `[:lower:]`: строчные буквы.
- `[:upper:]`: прописные буквы.
- `[:digit:]`: цифры.
- `[:alpha:]`: буквы.
- `[:alnum:]`: буквы и цифры.
- `[:space:]`: пробельные символы.
- `[:punct:]`: знаки препинания.

Например, преобразуем строчный текст в прописной с помощью классов:

```bash
$ echo "linux journey" | tr '[:lower:]' '[:upper:]'
LINUX JOURNEY
```

Параметр `-c` дополняет `SET1`, то есть выбирает каждый символ, не входящий в набор. Объедините его с `-d`, чтобы оставить только выбранные виды символов:

```bash
$ echo "user@example.com!" | tr -cd '[:alnum:]'
userexamplecom
```

Команда также удаляет перевод строки, поскольку он не является буквой или цифрой. Если важны границы записей, добавляйте или сохраняйте разделители намеренно.

:::single-choice{#tr-keep-alphanumeric}
Что делает `tr -cd '[:alnum:]'` с stdin?

::option[Удаляет буквы и цифры, оставляя всё остальное.]{#tr-delete-alnum explanation="Дополнение меняет набор, на который действует `-d`; сам буквенно-цифровой набор сохраняется."}
::option[Удаляет каждый символ, не являющийся буквой или цифрой.]{#tr-delete-nonalnum .correct explanation="`-c` дополняет буквенно-цифровой набор, а `-d` удаляет получившийся набор небуквенно-цифровых символов."}
::option[Преобразует каждую букву и цифру в верхний регистр.]{#tr-uppercase-alnum explanation="Набор назначения отсутствует, поэтому команда не выполняет изменение регистра."}
:::

## Построение потоковых преобразований

Несколько процессов `tr` можно соединить, если преобразования понятнее как отдельные этапы:

```bash
$ echo "Hello,,,     world!!!" | tr -d '[:punct:]' | tr -s ' '
Hello world
```

Для простого ввода с табуляциями преобразуйте их в запятые:

```bash
$ printf "name\tlevel\npete\tbeginner\n" | tr '\t' ','
name,level
pete,beginner
```

Поскольку `tr` читает stdin, файл можно предоставить через `<`:

```bash
$ tr '[:lower:]' '[:upper:]' < names.txt
```

Чтобы сохранить результат, перенаправьте stdout в другой файл. Не направляйте его обратно во входной путь: оболочка усечёт файл до того, как `tr` прочитает его.

:::single-choice{#tr-read-file-input}
Какая команда заставляет `tr` прочитать `names.txt` через stdin и преобразовать строчные символы в прописные?

::option[`tr names.txt '[:lower:]' '[:upper:]'`]{#tr-file-operand explanation="`tr` не принимает обычное имя входного файла таким способом; лишний операнд делает синтаксис недопустимым."}
::option[`tr -d '[:lower:]' < names.txt`]{#tr-delete-lowercase explanation="Файл читается правильно, но строчные буквы удаляются, а не преобразуются."}
::option[`tr '[:lower:]' '[:upper:]' < names.txt`]{#tr-input-redirection .correct explanation="Оболочка открывает `names.txt` как stdin, а `tr` сопоставляет класс строчных букв классу прописных."}
:::

2. Удаляйте выбранные символы параметром `-d`.
