Команда `paste` объединяет строки в столбцы. По умолчанию она берёт по одной строке из каждого входного файла, соединяет их табуляцией и повторяет это, пока не будет достигнут конец всех файлов.

## Объединение файлов бок о бок

Создайте два небольших файла:

```bash
$ printf 'alice\nbob\n' > names.txt
$ printf 'admin\nviewer\n' > roles.txt
```

Передайте оба файла команде `paste`:

```bash
$ paste names.txt roles.txt
alice	admin
bob	viewer
```

Видимый промежуток между столбцами является табуляцией. В отличие от `cat`, которая записывает один полный файл за другим, `paste` объединяет соответствующие входные строки.

:::single-choice{#paste-corresponding-lines} `first.txt` содержит `A`, затем `B`, а `second.txt` — `1`, затем `2`. Что по умолчанию выведет `paste first.txt second.txt`?

::option[`A`, `B`, `1` и `2` в четырёх последовательных строках.]{#paste-concatenated-files explanation="Так выглядела бы последовательная запись файлов. `paste` вместо этого объединяет соответствующие строки."}
::option[`A`, `B`, `1` и `2` в одной строке без разделителей.]{#paste-one-line-no-separator explanation="Для сериализации в одну строку нужен `-s`, а стандартный разделитель — табуляция, а не пустая строка."}
::option[`A` вместе с `1`, затем `B` вместе с `2`, разделённые табуляцией.]{#paste-parallel-result .correct explanation="В стандартном параллельном режиме для каждой выходной строки берётся по одной строке из каждого файла, а поля разделяются табуляцией."}
:::

## Выбор разделителя

Используйте `-d LIST`, чтобы заменить стандартную табуляцию. Например, двоеточием:

```bash
$ paste -d ':' names.txt roles.txt
alice:admin
bob:viewer
```

Заключайте в кавычки разделители, имеющие особое значение для оболочки. Если список содержит несколько символов, `paste` может циклически использовать их, но при построении двух столбцов проще всего применять один символ.

:::single-choice{#paste-colon-delimiter} Какая команда объединяет соответствующие строки `names.txt` и `roles.txt` двоеточием?

::option[`paste -d ':' names.txt roles.txt`]{#paste-colon-files .correct explanation="Параметр `-d` заменяет стандартную табуляцию указанным двоеточием для каждой пары полей."}
::option[`paste -s ':' names.txt roles.txt`]{#paste-serial-colon-operand explanation="Параметр `-s` выбирает последовательный режим, а `:` будет считаться ещё одним входным путём, а не разделителем."}
::option[`paste names.txt ':' roles.txt`]{#paste-colon-file-operand explanation="Без `-d` каждый операнд считается входным файлом, поэтому команда попытается открыть файл с именем `:`."}
:::

## Сериализация строк одного файла

Параметр `-s` обрабатывает каждый входной файл последовательно, объединяя его строки в одну выходную строку. Создайте файл с одним словом в строке:

```bash
$ printf 'The\nquick\nbrown\nfox\n' > words.txt
$ paste -s words.txt
The	quick	brown	fox
```

Объедините `-s` с `-d`, чтобы выбрать разделитель:

```bash
$ paste -s -d ' ' words.txt
The quick brown fox
```

Если с `-s` указано несколько файлов, каждый файл превращается в отдельную выходную строку.

:::single-choice{#paste-serialize-with-spaces} Какая команда объединяет все строки `words.txt` в одну строку, разделяя их пробелами?

::option[`paste -d ' ' words.txt`]{#paste-parallel-one-file explanation="В стандартном параллельном режиме один входной файл по-прежнему даёт по одной выходной строке на входную. Разделителю нечего соединять между файлами."}
::option[`paste -s words.txt roles.txt`]{#paste-two-serial-files explanation="Эта команда сериализует два файла отдельно со стандартной табуляцией и выдаст две строки вместо требуемого результата из одного файла с пробелами."}
::option[`paste -s -d ' ' words.txt`]{#paste-serial-spaces .correct explanation="`-s` сериализует строки файла, а `-d ' '` помещает между ними пробел."}
:::

## Файлы разной длины

Если в параллельном режиме входные файлы содержат разное число строк, `paste` продолжает работу до конца самого длинного. Отсутствующие значения более короткого файла становятся пустыми полями:

```bash
$ printf 'A\nB\nC\n' > letters.txt
$ printf '1\n2\n' > numbers.txt
$ paste -d ':' letters.txt numbers.txt
A:1
B:2
C:
```

:::single-choice{#paste-unequal-files} Что происходит, когда один файл в параллельной команде `paste` заканчивается раньше другого?

::option[`paste` подставляет для него пустые поля, пока не закончится самый длинный ввод.]{#paste-empty-fields .correct explanation="Параллельный режим работает до исчерпания всех файлов, представляя отсутствующие строки коротких файлов пустыми полями."}
::option[`paste` немедленно останавливается и отбрасывает оставшиеся строки.]{#paste-stop-shortest explanation="Команда продолжает работу до конца самого длинного ввода, поэтому строки не отбрасываются лишь из-за завершения другого файла."}
::option[`paste` повторяет короткий файл с начала.]{#paste-repeat-shorter explanation="Команда не зацикливает входные записи. Исчерпанный ввод предоставляет пустые поля."}
:::

## Чтение одного ввода из stdin

Используйте `-` как файловый операнд, чтобы читать в этой позиции из stdin:

```bash
$ printf 'admin\nviewer\n' | paste -d ':' names.txt -
alice:admin
bob:viewer
```

:::single-choice{#paste-stdin-operand} Что означает операнд `-` в `producer | paste names.txt -`?

::option[Записывать объединённый результат в stderr.]{#paste-write-stderr explanation="Дефис здесь обозначает источник ввода и не перенаправляет выходной поток."}
::option[Удалить разделители между двумя столбцами.]{#paste-remove-delimiter explanation="Разделитель выбирается параметром `-d`; дефис его не изменяет."}
::option[Читать этот входной столбец из stdin.]{#paste-read-stdin .correct explanation="Дефис указывает `paste` использовать стандартный ввод в этой позиции операнда."}
:::
