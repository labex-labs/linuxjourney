Команда `uniq` сравнивает каждую входную строку с предыдущей. Она может сворачивать, подсчитывать и выбирать группы соседних одинаковых строк, но не ищет разделённые дубликаты по всему файлу.

## Свёртывание соседних повторяющихся строк

Предположим, `reading.txt` содержит сгруппированные значения:

```plaintext
book
book
paper
paper
article
article
magazine
```

Запустите `uniq` без параметров фильтрации, чтобы вывести по одной строке из каждой соседней группы:

```bash
$ uniq reading.txt
book
paper
article
magazine
```

Входной файл не изменяется, поскольку результат поступает в stdout.

:::single-choice{#uniq-collapse-adjacent} Что по умолчанию делает `uniq reading.txt`?

::option[Сортирует весь файл, а затем удаляет каждое повторяющееся значение.]{#uniq-auto-sort explanation="`uniq` сохраняет порядок ввода и не сортирует его. Разделённые копии остаются отдельными группами."}
::option[Выводит по одной строке из каждой соседней группы одинаковых строк.]{#uniq-one-per-group .correct explanation="По умолчанию `uniq` сворачивает последовательные одинаковые строки в одну выходную."}
::option[Удаляет повторяющиеся строки непосредственно из `reading.txt`.]{#uniq-edit-file explanation="По умолчанию команда записывает отфильтрованный текст в stdout и не редактирует входной файл."}
:::

## Подсчёт соседних групп

Используйте `-c`, чтобы добавить перед каждой выходной группой количество последовательных входных строк:

```bash
$ uniq -c reading.txt
      2 book
      2 paper
      2 article
      1 magazine
```

Это длины последовательностей, а не глобальные количества, если только все одинаковые строки заранее не были сделаны соседними.

:::single-choice{#uniq-count-groups} Что обозначает число от `uniq -c`?

::option[Количество символов в каждой входной строке.]{#uniq-character-count explanation="`uniq -c` не считает символы; общие количества символов и байтов определяют инструменты вроде `wc`."}
::option[Количество последовательных одинаковых строк в каждой группе.]{#uniq-consecutive-count .correct explanation="`-c` добавляет к каждой свёрнутой соседней группе число входивших в неё строк."}
::option[Общее число совпадающих строк во всём файле.]{#uniq-global-count explanation="Разделённые одинаковые строки образуют отдельные группы, если данные сначала не отсортированы или иначе не сгруппированы."}
:::

## Выбор уникальных и повторяющихся групп

Используйте `-u`, чтобы вывести только группы ровно из одной строки:

```bash
$ uniq -u reading.txt
magazine
```

Используйте `-d`, чтобы вывести одну строку из каждой соседней группы, содержащей более одной строки:

```bash
$ uniq -d reading.txt
book
paper
article
```

GNU `uniq -D` выводит все строки повторяющихся групп, тогда как строчная `-d` — значение каждой такой группы один раз.

:::single-choice{#uniq-only-singletons} Какая команда выводит только соседние группы, встречающиеся ровно один раз?

::option[`uniq -c reading.txt`]{#uniq-count-reading explanation="Эта команда выводит каждую группу с количеством, включая повторяющиеся и одиночные."}
::option[`uniq -d reading.txt`]{#uniq-duplicate-reading explanation="Строчная `-d` выводит по одной строке для повторяющихся групп — противоположную выборку."}
::option[`uniq -u reading.txt`]{#uniq-single-reading .correct explanation="Параметр `-u` выбирает группы с длиной соседней последовательности ровно один."}
:::

:::single-choice{#uniq-one-per-duplicate-group} Какая команда выводит по одной строке для каждой соседней группы, встречающейся более одного раза?

::option[`uniq -d reading.txt`]{#uniq-duplicate-groups .correct explanation="Параметр `-d` выбирает повторяющиеся соседние группы и выводит по одной представляющей их строке."}
::option[`uniq -D reading.txt`]{#uniq-all-duplicate-lines explanation="GNU-параметр `-D` в верхнем регистре выводит все строки повторяющихся групп, а не одну представляющую."}
::option[`uniq -u reading.txt`]{#uniq-unique-groups explanation="Параметр `-u` выбирает одиночные, а не повторяющиеся группы."}
:::

## Группировка разделённых дубликатов

Если одинаковые строки разделены, они образуют разные группы:

```plaintext
book
paper
book
paper
article
magazine
article
```

Запуск `uniq` для такого файла даст неожиданный результат:

```bash
$ uniq reading.txt
book
paper
book
paper
article
magazine
article
```

Ни одна строка не сворачивается, поскольку соседние значения различаются. Если изменение порядка допустимо и нужно сгруппировать одинаковые полные строки, сначала выполните сортировку:

```bash
$ sort reading.txt | uniq
article
book
magazine
paper
```

Используйте согласованные локаль и правила сравнения на обоих этапах. `sort -u reading.txt` также может за одну команду отсортировать данные и оставить по одной строке на каждый одинаковый ключ сортировки.

:::single-choice{#uniq-separated-duplicates} Одинаковые строки разбросаны по `reading.txt`, а порядок вывода можно изменить. Какой конвейер выдаёт по одной отсортированной копии каждой различающейся полной строки?

::option[`sort reading.txt | uniq`]{#sort-then-uniq .correct explanation="Сортировка группирует одинаковые полные строки, после чего `uniq` сворачивает каждую соседнюю группу в одну строку."}
::option[`uniq reading.txt | sort`]{#uniq-before-sort explanation="`uniq` выполняется до того, как разделённые одинаковые строки станут соседними, поэтому после сортировки в выводе могут остаться дубликаты."}
::option[`uniq -c reading.txt | head`]{#uniq-count-head explanation="Команда считает существующие соседние группы, а затем ограничивает вывод и не группирует разделённые дубликаты глобально."}
:::

`uniq` читает stdin, если входной файл не указан, поэтому естественно располагается после `sort`. Параметр GNU `-i` позволяет игнорировать регистр, а `-f`, `-s` и `-w` — пропускать или ограничивать области сравнения; применяйте их только тогда, когда равенство должно определяться частью строки.

3. **[Подсчёт слов и сортировка](https://labex.io/ru/labs/linux-word-count-and-sorting-388125)** — примените `wc` и `sort` для подсчёта строк, слов и символов, поиска частых закономерностей и сортировки данных.

## Итоги

Теперь вы можете анализировать соседние группы одинаковых строк с помощью `uniq`.

1. Сворачивайте каждую соседнюю группу дубликатов в одну строку.
2. Считайте последовательные вхождения параметром `-c`.
3. Выбирайте одиночные группы параметром `-u`.
4. Выбирайте повторяющиеся группы параметрами `-d` или GNU `-D`.
5. Сначала сортируйте данные, если нужно сгруппировать разделённые дубликаты.
