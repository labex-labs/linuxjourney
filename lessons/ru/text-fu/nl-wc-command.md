Команда `wc` подсчитывает характеристики текстовых потоков, а `nl` записывает входные данные с созданными номерами строк. Обе команды читают файлы или stdin и отправляют результаты в stdout.

## Чтение стандартного вывода wc

Без параметра вида подсчёта `wc` выводит число символов перевода строки, слов и байтов, а затем имя файла, если оно было указано:

```bash
$ printf 'red blue\ngreen\n' > colors.txt
$ wc colors.txt
 2  3 15 colors.txt
```

Слева направо:

1. `2` символа перевода строки, представленные как строки.
2. `3` слова, разделённые пробельными символами.
3. `15` байтов в этом примере ASCII.

Последняя текстовая строка без завершающего перевода строки не учитывается `wc -l`, поскольку этот параметр считает символы перевода строки, а не визуально воспринимаемые строки.

## Запрос одного значения

Выберите только нужное измерение:

- `-l`: число символов перевода строки.
- `-w`: число слов.
- `-c`: число байтов.
- `-m`: число символов согласно текущей локали.

Например:

```bash
$ wc -w colors.txt
3 colors.txt
```

Для текста ASCII число байтов совпадает с числом символов, но в многобайтовых кодировках вроде UTF-8 они могут различаться. При использовании stdin без файлового операнда `wc` обычно не выводит метку имени файла:

```bash
$ printf 'one two\n' | wc -w
2
```

::option[`wc -c essay.txt`]{#wc-bytes-essay explanation="Параметр `-c` сообщает число байтов, а не разделённых пробелами слов."}
:::

:::single-choice{#wc-characters-not-bytes} Какой параметр просит `wc` считать символы, а не байты, в текущей локали?

::option[`-m`]{#wc-character-option .correct explanation="Параметр `-m` сообщает число символов, которое может отличаться от числа байтов в многобайтовом тексте."}

::option[`-w`]{#wc-word-option explanation="Параметр `-w` считает слова, а не символы или байты."}

Если указано несколько файлов, `wc` выводит результат для каждого и строку `total`. GNU `wc -L` сообщает максимальную отображаемую ширину входной строки.

## Нумерация непустых строк с помощью nl

По умолчанию `nl` нумерует непустые строки логического тела входных данных. Предположим, `notes.txt` содержит пустую вторую строку:

```text
alpha

beta
```

Пустая строка сохраняется, но не получает номера:

```bash
$ nl notes.txt
	 1	alpha

	 2	beta
```

`nl` записывает нумерованный вывод и не изменяет `notes.txt`.

::option[Полностью удаляет каждую пустую строку из вывода.]{#nl-omit-blank explanation="Пустая строка остаётся в выводе, но по умолчанию номер ей не назначается."}
::option[Сохраняет их без номеров.]{#nl-preserve-unnumbered .correct explanation="Стандартный стиль тела нумерует непустые строки и пропускает пустые без номера."}
::option[Нумерует их в одной последовательности с непустыми.]{#nl-number-blank-default explanation="Для нумерации каждой строки тела нужен другой стиль, например `-ba`."}
:::

## Нумерация каждой строки

Используйте `-ba`, чтобы выбрать стиль тела `a`, нумерующий все строки:

```bash
$ nl -ba notes.txt
	 1	alpha
	 2
	 3	beta
```

Другие параметры управляют форматированием. Например, `-w 3` задаёт ширину поля номера, а `-s ': '` изменяет разделитель после него.

:::single-choice{#nl-number-all-lines} Какая команда нумерует каждую строку тела `notes.txt`, включая пустые?

::option[`nl -w 3 notes.txt`]{#nl-width-three explanation="Эта команда меняет ширину поля номера, но сохраняет стандартное правило нумерации только непустых строк."}
::option[`nl -ba notes.txt`]{#nl-body-all .correct explanation="Параметр `-b` выбирает стиль тела, а стиль `a` нумерует все строки."}
::option[`wc -l notes.txt`]{#wc-lines-notes explanation="Эта команда выводит число переводов строк и не воспроизводит файл с номерами строк."}
:::

Теперь вы можете измерять текстовые потоки и добавлять видимые номера строк, не редактируя источник.

3. Отличайте число байтов от числа символов.
4. Нумеруйте непустые строки стандартным поведением `nl`.
5. Нумеруйте также пустые строки с помощью `nl -ba`.
