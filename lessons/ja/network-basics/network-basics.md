ネットワークはインターフェースを接続し、異なるホストのアプリケーションがデータを交換できるようにします。経路の各部分をどのデバイス、アドレス、リンクが扱うかを理解すると、Linux コマンドを解釈しやすくなります。

## ホストとインターフェース

ホストは、ノート PC、サーバー、電話、仮想マシンなどのネットワーク接続システムや端点です。1つのホストが Ethernet、Wi-Fi、ループバック、トンネル、ブリッジ、仮想アダプターなど複数のインターフェースを持つ場合があります。それぞれに技術に合ったリンク層とネットワーク層の設定を持たせられます。

Linux ホストのインターフェースとアドレスを調べます。

```bash
$ ip address show
```

インターフェースが存在し、管理上 up であっても、端から端までの接続は証明できません。

## ローカルネットワーク

LAN（ローカルエリアネットワーク）は、家庭、オフィス、データセンターの区画など限られた範囲を扱います。Ethernet スイッチはローカルリンクのポート間でフレームを転送します。WLAN は無線リンク技術を使う LAN です。ブリッジやアクセスポイントが接続すれば、有線と無線のインターフェースを同じ IP サブネットに含めることもできます。

::option[WLAN は常に別の世界規模インターネットである。]{#network-basics-wlan-global explanation="無線リンク技術を使うローカルネットワークです。"}
::option[WLAN はルーターが使うディスクパーティションである。]{#network-basics-wlan-disk explanation="ネットワークを表す用語で、ストレージ構成ではありません。"}
::option[WLAN は無線形式のローカルエリアネットワークである。]{#network-basics-wlan-local .correct explanation="無線リンクと有線リンクを1つのローカルブロードキャストドメインへブリッジすることもできます。"}
:::

## ルーターと広域ネットワーク

ルーターはルーティングテーブルに従い、IP ネットワーク間でネットワーク層のパケットを転送します。家庭用機器はルーティング、スイッチング、Wi-Fi アクセス、ファイアウォール、NAT、DHCP を組み合わせることがありますが、これらは別々の機能です。

WAN（広域ネットワーク）は、より大きな地理的・管理的境界にまたがります。ISP は顧客ネットワークをほかのネットワークへ接続できますが、WAN は単に「家の外の全デバイス」を意味しません。

## パケット、フレーム、フロー

アプリケーションのデータはプロトコル層で分割・カプセル化されます。IP はネットワーク間でパケットを運び、ローカルリンクは各パケットを技術固有のフレーム内で運びます。通常、ルーターは IP パケットを先へ転送するとき、ホップごとにリンク層のフレームを置き換えます。

1つの会話には双方向の多数のパケットが関わります。損失、順序変更、断片化、再送、経路変更があるため、1個の取得パケットだけではアプリケーションのトランザクション全体を説明できないことが普通です。

::option[同じ Ethernet フレームがインターネット全体を変更なしで渡る。]{#network-basics-same-frame explanation="フレームの範囲はリンク内で、ルーターホップごとに置き換えられます。"}

## まとめ

基本的なネットワーク経路を構成する主な要素を説明できるようになりました。

1. ホストと、その物理・仮想インターフェースを区別する。
2. 有線と無線のローカルネットワークを見分ける。
3. 複合型の家庭用機器で、ルーティングとほかの機能を区別する。
4. リンクフレームとルーティングされる IP パケットを区別する。
