Linux history

From UNIX to GNU/Linux

  1. 1969

    UNIX is created

    Ken Thompson and Dennis Ritchie create UNIX at Bell Labs.

  2. 1973

    UNIX kernel
    rewritten in C

    This lays the groundwork for later portability across hardware systems.

  3. 1983–1984

    The GNU Project

    Announced by Richard Stallman in September 1983; development begins in January 1984.

  4. February 1989

    GNU GPL version 1
    is published

    The first version of the GNU General Public License (GPLv1).

  5. 1991

    The Linux kernel

    Linus Torvalds starts developing the Linux kernel.

  6. 1992

    Linux adopts the GPL

    Together with GNU components, it forms a complete free operating system.
